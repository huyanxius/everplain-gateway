# API behavior

The complete pinned upstream API is retained. No Everplain text-only route guard, separate RPM cap, normalized-error wrapper, disabled-commerce middleware or replacement billing/usage contract is installed.

Use the pinned upstream documentation and configuration for API-key authentication, provider-specific routes, model mappings, quotas, user balances, subscriptions, billing, usage, streaming, cancellations and retries. The original standard/simple modes remain upstream options. No additional lightweight profile is included.

Do not infer configured model access from source support or UI visibility. No live provider account has been configured or verified by this delivery. Manual account setup remains the operator's choice; see PROVIDER_SETUP.md for the retained Antigravity flow and its external side effects.

Earlier checkpoint usage/load results applied to a now-removed text-only profile and synthetic fixture. They are historical evidence only and do not establish the current full distribution's API/resource acceptance.
